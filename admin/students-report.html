Student list & QR codes

Student login credentials

Each student gets a random temporary password by e-mail and must change it at first login. Students who already have credentials are skipped. A password is saved only after its e-mail has been sent.

Each QR code holds a signed ID (for example LVRMIC26-S001), so a code that was not generated here is rejected by the scanner. Tick people to print only them; with nothing ticked, everyone in the current filter is printed.
