Meal configuration

Tick the days and meals students get. Only ticked items appear on each coupon, one punch circle per day. Saved in this browser.

In the print window set margins to None and turn on Background graphics. Cut the cards along the dashed lines. On the coupons, punch the circle for the meal when it is taken.

Press Generate ID cards or Generate meal coupons. Compare themes shows the first selected student in every colour theme.
